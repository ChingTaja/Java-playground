# Getter
Getter 是一個在類別上的方法
用來取得（retrieve）某個 **private 欄位的值**
並將它回傳


# Setter
Setter 是一個在類別上的方法，用來設定（set）某個 **private 欄位**的值



另一個很重要的觀念是：

Getter 和 Setter 的「方法簽名（method signatures）」
是類別對外公開介面（public interface）的一部分，

但 field name 與 type 並不是。

這代表：

我可以在 Classs 內部改變某個欄位的名稱或型別

只要我保留相同的 getter 和 setter 方法
外部使用這個類別的程式碼就不會受到影響 
換句話說，我們的內部修改會被隱藏起來，不會影響使用者
==> 封裝（Encapsulation）


一般慣例是：
使用 get 作為前綴，加上欄位名稱（小駝峰命名法 lower camel case）
不過這並不是強制規定

有些 getter 方法甚至可以回傳「計算出來的值」，
而**不一定是直接對應某個實際存在的欄位**

Setter 方法通常只是把傳進來的參數指派給欄位，

但它也可以包含：

驗證資料是否合法

檢查安全性條件

確保欄位不可變（immutability）

或任何保護物件狀態的邏輯

一般慣例是：

使用 set 作為前綴，加上欄位名稱（小駝峰命名法）。

但同樣的，這只是命名習慣，不是語法強制規定。

而且有很多情況下，

某些 private 欄位可能根本不需要 setter。

也許那是只在類別內部使用的資料，

不需要暴露給外部世界。
