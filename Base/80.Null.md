# Null
null 是 Java 裡的一個特殊 keyword

表示： 這個變數或屬性有「型別」，但它沒有指向任何物件。

意思是說，
這個變數**沒有被指派任何實例（instance）或物件**

原始型別（primitive data types）的欄位永遠**不會是 null**

那為什麼 car 的 color、make 和 model 是 null？

因為這些欄位都是 String 型別
而我沒有幫它們指定任何值。

而我們在之前學過，
**String 其實是物件**，不是 primitive 型別
所以 Java 自動幫它們指定為 null 參考

另外你應該注意到：

(Basic.java)
doors 被印出來是 0

convertible 這個字沒有出現在輸出裡 

為什麼會這樣？
明明沒有幫 doors 或 convertible 指定值
但執行時卻沒有錯誤

這裡就出現了：
# 區域變數（local variable）和類別欄位（field）的差別
local variable -> 宣告在方法裡面的變數
Class field -> 宣告在 class 裡面、方法外面的變數

Java 的規則是：
如果你沒有幫「類別的欄位」指定值(沒有指定初始值的話)，Java 會自動幫你設定**「預設值」**

預設值如下：
型別  -> 預設值
數字（int, long, short）->	0
double / float	-> 0.0
boolean	 -> false
物件（例如 String） -> null
