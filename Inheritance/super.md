1. super() 是什麼？
   它是用來呼叫「父類別（Animal）」 constructor 的語法

this()：呼叫「自己類別」裡的其他構造函數
super()：呼叫「爸爸類別」的構造函數

2. 第一行準則 
   在子類（Dog）的構造函數裡，呼叫父類構造函數的操作 必須放在第一行

因為 Java 規定：你必須先初始化「父類的部分」，才能處理「子類自己的東西」

副作用： 因為 this() 和 super() 都搶著要當第一行，所以它們不能同時出現在同一個構造函數裡

3. Java 的「自動補位」
   如果你在 Dog 的構造函數裡什麼都不寫，Java 會貼心地幫你補上一行隱形的 super();

這就是為什麼當 Animal 沒有「無參數構造函數」時會報錯——因為 Java 自動補的那行 super();

4. 沒 default construtor 怎麼辦？
   因為 Animal 已經定義了「有參數」的構造函數，所以原本自動生成的「無參數構造函數」消失了
解決方法： 你必須在 Dog 的構造函數裡，「手動」傳入正確的參數給父類
