
Record 它的核心目標是「用最少程式碼，包裝一份絕對不能被修改的資料」。因此，它的欄位在底層全都是 `final`（一旦指派就不能變更）

### 1. Record 建構子的三種形式（Flavors）

- 標準建構子（Canonical / Long Constructor）：
    
    - 編譯器預設會自動生成的隱式建構子，參數的型別與順序和 Record 的宣告完全一致
        
    - 若要顯式手動宣告它，必須確保所有 `final` 欄位都有被明確指派數值
        
- 自訂建構子（Custom Constructor）：
    
    - 屬於多載（Overloaded）建構子（如講稿中的 Copy Constructor）
        
    - 關鍵限制：自訂建構子的第一行敘述句，必須明確呼叫 `this(...)` 去委派給標準建構子
        
- 精簡建構子（Compact / Short Constructor）：
    
    - Record 專屬語法，外觀特徵是沒有小括號 `()`**（無參數列表描述）
        
    - 它是宣告標準建構子的一種簡潔方式，專門用來處理資料的驗證（Validation）與轉換（Transformation），省去了老套的欄位指派代碼
        

### 2. 精簡建構子（Compact Constructor）的底層運作與鐵律

Compact Constructor 的用途就在於：讓開發者「只專注寫驗證與加工的邏輯」，而把繁瑣、重複的欄位指派工作交給編譯器自動完成

- 程式碼注入機制：精簡建構子內寫的程式碼，會被編譯器排在`隱式標準建構子的最前面執行`，也就是在 `final` 欄位被實際指派之前跑完
    
- 參數 vs. 實例欄位（不要混淆）：
    
    - 在精簡建構子中，你擁有標準建構子所有引數（如 `name`, `dob`）的存取與修改權限，可以對這些`參數變數`重新賦值（如 `dob = ...`）
        
    - 你`絕對不能`在這個區塊內對`實例欄位`進行指派（例如寫 `this.dob = ...` 會引發錯誤）
        
    - 你也`絕對不能`在這個區塊內存取或使用實例欄位（例如呼叫 `this.dob.replace()`），因為此時 `final` 欄位`尚未初始化`


## 5 大核心鐵律

Compact Constructor 在 Java 底層設計上的規則：

1. 獨特的語法特徵（No Parentheses）：
    
    - 宣告精簡建構子時，**絕對不加小括號 `()`**，所以表面上看起來沒有參數
        
2. 隱形擁有所有參數存取權：
    
    - 雖然外觀沒有寫參數，但它`完全可以存取`標準建構子的所有傳入引數（例如可以直接拿 `name`、`dob` 來用）
        
3. 「參數」與「實例欄位」不能混淆（核心盲點）：
    
    - 在精簡建構子裡面，你摸到的變數（如 `dob`）只是「建構子的參數變數」
        
    - 你此時`絕對不能`對實例欄位進行指派（例如寫 `this.dob = ...` 會直接引發編譯錯誤）
        
4. 欄位指派會「延後執行」：
    
    - 編譯器自動幫你把參數塞進 `final` 欄位的隱式程式碼（即 `this.name = name;`），是在這段精簡建構子的程式碼**完全執行完畢之後**，才會在底層默默發生
      
```java
public Person {
    // 步驟 1：東西還在保險箱外面
    // 你可以對它摸來摸去、檢查、甚至加工改裝
    dob = dob.replace('-', '/'); // 成功把橫線換成斜線
    
} // ⬅️ 到了大括號結束的這個瞬間！

	// 步驟 2：【延後執行】的鎖箱子作業，現在才默默登場
	// Java 在後台自動幫你把剛剛「改裝好」的成品鎖進去：
	// this.name = name;
	// this.dob = dob;
```
        
5. 王不見王的互斥限制：
    
    - 在同一個 Record 當中，`精簡建構子`（Compact）與`顯式的標準建構子`（Explicit Canonical）具有完全的`互斥性`，你只能二選一，絕對不能同時寫出來
    - 因為不論是 **Compact 形式** 還是 **Explicit Canonical（顯式標準）形式**，它們最終的目的，都是要定義出**同一個真身**——也就是那個「參數型別與順序完全對應 Record 宣告的標準建構子」
