# 線性搜尋 (Linear Search) 與 二分搜尋 (Binary Search)

1. 線性搜尋 (Linear Search)
這是最直觀、最簡單的搜尋方式，屬於 順序型 (Sequential) 搜尋。

運作原理：

從陣列的第一個元素（索引 0）開始。

逐一比對每個元素，直到找到匹配的值或檢查完所有元素。

結果回傳：

若找到：回傳索引位置（Index）或 true。

若未找到：回傳 -1 或 false。

特性： 無論資料是否有序（Sorted）都可以使用，但資料量大時效率較低

2. 二分搜尋 (Binary Search)
這是一種高效率的搜尋法，屬於 區間型 (Interval) 搜尋

運作原理：

每次都檢查目前區間的 中間值 (Middle)

若目標比中間值大，就去右半邊找；若目標比中間值小，就去左半邊找

每次比對都能剔除掉一半的資料，範圍迅速縮小

`重要前提： 資料 必須已經排序好（例如從小到大`

# Arrays.binarySearch()

1. 
搜尋結果的判讀找到目標時： 回傳該元素在陣列中的 索引位置 (Index)（即 >= 0的整數）
未找到目標時： 回傳 負數 -1 

2. 
處理「重複值」的限制不保證順序： 如果陣列中有重複的元素（例如有多個 10）
該方法不保證會回傳「第一個」出現的索引。隨機性： 它可能會回傳任何一個匹配到的 10 的位置
解決方案： 如果你的應用情境「一定要找到第一個」，則不建議直接使用 binarySearch，而需要改用傳統的 線性搜尋 或自定義的搜尋邏輯
